# Footprint Korea

## 1. 개요
  - 한국에 갔던 도시들(시, 군, 구 단위)을 언제 갔다왔는지, 어느 곳을 방문했는지, 그리고 느낌을 남길 수 있는 프로젝트다.

## 2. 기술스택
  - 회원가입 및 로그인과 로그아웃, 라우팅 기능을 포함한다.
  - 프론트엔드는 React, React Router, TailwindCSS, Vite, typescript를 사용한다.
  - 백엔드는 Supabase를 사용한다. 
  - 지도 서비스는 네이버지도 API를 이용한다.
  - 작은 모바일 디스플레이에 대응할 수 있도록 반응형 디자인을 사용한다.

## 3. ✅주요기능
  1. 로그인 페이지
  - ✅유저는 첫 페이지에서 회원가입과 로그인을 할 수 있도록 한다.
  - ✅향후 구글계정으로 로그인할 수 있도록 업데이트할 계획이다.
  2. ✅메인 페이지
  - ✅로그인을 하면 상단 바에 'OOO님, 환영합니다.'란 메시지와 함께, 로그아웃 버튼을 눌러서 로그아웃할 수 있도록 한다.
  - ✅로그인을 하면 가장 주요 부분에 방문했던 곳을 색상으로 칠한 레이아웃을 포함한 네이버지도를 보여준다.
  - ✅이와 함께 방문했던 곳을 전부 나타내는 목록을 수정/삭제 버튼과 함께 나타낸다.
  - 향후 날짜별, 위치별, 장소 카테고리별 필터링 기능을 추가할 계획이다.
  - ₩새 방문지 생성₩ 버튼을 클릭하면 방문한 곳을 등록할 수 있는 페이지로 넘어간다.
  3. ✅새 방문지 페이지
  방문했던 곳의 이름, 방문한 기간, 방문한 곳의 유형, 그리고 감상을 남길 수 있는 텍스트를 유저로부터 입력받을 수 있다.
  - ✅저장 버튼을 누르면 방문한 곳을 백엔드 데이터베이스에 등록할 수 있도록 한다.
  - ✅저장 버튼을 누르면 메인 페이지로 돌아갈 수 있도록 한다.
  4. ✅방문지 수정 페이지
  - ✅등록한 방문지를 수정할 수 있는 페이지다.
  - ✅방문한 곳의 이름, 방문한 기간, 방문한 곳의 유형, 감상을 남길 수 있는 텍스트를 수정할 수 있도록 한다.
